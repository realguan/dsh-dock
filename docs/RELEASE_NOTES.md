# DSH Dock 版本发布与升级日志 (Release Notes)

> 本文档记录 DSH Dock 各版本的核心演进、功能特性、交互优化与缺陷修复历史。

---

## [v1.0.0] - 2026-09-10

### 🌟 核心亮点 (Highlights)
- **DSH Dock 1.0 正式发布**：启动体验双模重塑——日常启动秒进、多工作台走全新「启动台」；会话自愈新增世代分叉修复；三平台应用图标与文档焕新为专属品牌形象。

### ✨ 新增功能 (Features)
- **工作台启动台（Launchpad）**：多工作台时以卡片网格呈现全部工作台及其运行态、默认标签与插件数，支持数字键 `1-9` 快捷直达与「记住我的选择」（下次启动直接进入）；单工作台场景走秒启 Splash，不再打断启动。
- **DSH 版本选择器**：从 Registry 拉取全版本列表，按稳定 / 候选 / 预览（Stable / RC / Alpha）通道标注并显示发布日期，可安装任意历史版本或回退到旧版；预览版需显式选择才会升级，日常「有新版」判定仍只认稳定 / 候选。
- **插件市场安装队列与下载管理**：异步安装不阻塞界面，实时呈现排队中 / 安装中 / 已安装 / 失败状态，配可收起的下载管理面板与安装抛物线动画。
- **补丁包启用 / 禁用开关**：依据 dump 段落归属映射生成贡献行，可单独停用某个补丁包而无需卸载。
- **破坏性操作统一确认与覆写前备份**：所有覆写类操作（凭据、引擎设置等）先落 `.bak-<时间戳>` 备份，并在执行前给出统一确认。

### 🛠️ 体验与交互优化 (Improvements)
- **启动链路**：新增日常秒启 Splash；工作台选择页撤除通栏顶栏；引擎已就绪时启动短路，去掉冗余等待。
- **会话维护**：`unknown` 状态独立呈现（不再与「需自愈」混淆）；会话行信息去重，字号刻度与断点对齐，页头吸顶。
- **可访问性**：键盘与读屏可达性补齐（表单标签、标题层级、toast live region、控件可读名称）；表单对比度达标并清理 dark 变体残留。
- **界面一致性**：图标与动词统一、长串截断补齐 `title` 提示、弹窗横向截断根治（grid 轨道被 nowrap 长串顶开的根因）。
- **品牌形象**：3D 鲸鱼娘 Whale-chan 成为客户端图标与页内徽章的统一形象（透明切图 + Apple HIG 圆角方框，四周透明度强门禁）。
- **文档**：README 按模块重构并配 14 张实拍界面图，新增更新日志入口与首次启动联网说明。

### 🐛 缺陷修复 (Bug Fixes)
- **会话自愈**：修复成功后失效 dsh 投影缓存（stale blank 投影导致侧栏隐藏）；迁移器不再把无法归类的会话标记为 `unknown`，消除「需自愈」误报。
- **插件市场**：修复非 npm 来源（GitHub / tarball）安装必败；修正 git 来源插件的已装状态判定（补声明 spec 连接键）。
- **外挂插件清单**：DSH 官方桌面运行时内置的 `desktop-packages` 不再被当作第三方外挂插件展示。
- **导航**：壳页面回流改用原生 `navigate`（替代注入 `location.assign`），消除启动与切换运行模式时的白屏与竞态。
- **运行日志**：`plugin-op.log` 改为追加式 + 轮转，失败历史不再被单次操作覆盖。

### 🔒 架构、安全与稳定性 (Security & Stability)
- **启动失败类型化**：boot 路径引入 `BootFailure` 枚举，子串分类降级为 `from_legacy_detail` 兜底（ADR-0012）。
- **插件职责边界立宪**：跨 profile 归插件中心、单 profile 归详情；安装来源三形态白名单（npm / GitHub / tarball），更新检查保持严格 npm 判别（ADR-0011）。
- **构建脚本默认批准**：profile 级 `dangerouslyAllowAllBuilds`，逐包裁决链退役（ADR-0013）。
- **模块收敛**：拆分 `boot` / `ui` / `commands` 独立模块，注入脚本迁出 Rust 原始字符串；剪贴板写入收敛为唯一入口。
- **契约闸门**：IPC 契约「形状」跨语言闸门（`ipc-shapes.json` 与前端类型一致性测试）；网络面 HTTP seam 注入，镜像链可离线覆盖。
- **发版纪律**：落盘发版日志强契约（`## [vX.Y.Z] - YYYY-MM-DD`）与 CI 提取脚本严格模式，杜绝裸打 tag。

## [v0.9.6] - 2026-09-08

### 🌟 核心亮点 (Highlights)
- **pnpm 12 构建审批门产品化与运行态会话误判自愈**：插件安装遭遇依赖构建受阻时提供交互式白名单逐包审批；修复已结束会话状态识别反转；治理 MCP 循环刷新与全站重载按钮语义。

### ✨ 新增功能 (Features)
- **构建脚本审批交互链路**：当 pnpm 12 触发 `ERR_PNPM_IGNORED_BUILDS` 时，前端主动弹出逐包裁决对话框，支持受控写入 `pnpm-workspace.yaml` 的 `allowBuilds` 白名单并自动重试。

### 🛠️ 体验与交互优化 (Improvements)
- **会话状态感知纠正**：修复 `engine_session_alive` 逻辑反转导致的已结束会话误判「进行中」问题，增订 `endState` 降噪子句。
- **MCP 面板异常治理**：根治内联引用与 effect 造成的死循环刷新，改用面板内错误态并保留安全重试。
- **全站刷新与操作语义化**：移除多余的刷新控件，规范日志与凭据重新拉取的语义标签和图标。
- **启动选择页视觉降噪**：撤除 selector 页面冗余顶栏，收紧工作台悬浮胶囊挂载条件，消除本地页面误挂问题。

## [v0.9.4] - 2026-09-01

### 🌟 核心亮点 (Highlights)
- **Windows 与 WSL 跨平台启动体验全面加固**：落地 WSL 客体内 Node.js 全自动补齐链路（ADR-0004 §7）；优化首次准备环境等待反馈与平滑过渡；实现模式切换双向感知与控制中心 Win32 WebView2 防白屏。

### ✨ 新增功能 (Features)
- **WSL 客体内自动补齐 Node.js 运行时**：当 WSL 发行版缺少 Node 时，通过 npmmirror/nodejs.org 镜像链在客体内全自动拉取官方 Linux-x64 tarball 并解压至 `~/.dsh-dock/node`，串联 `node -> dsh` 自动化安装与校验。
- **模式切换双向感知**：启动页模式切换按钮动态识别当前环境，在 WSL 模式下支持一键切换回「在本机中打开」，Local 模式下支持「在 WSL 中打开」，支持双语国际化文案。

### 🛠️ 体验与交互优化 (Improvements)
- **环境准备阶段顶栏精简与拖拽优化**：启动准备期间精简顶栏，隐藏未就绪的控制中心入口与品牌字样，保留透明可拖拽区域与版本信息，就绪后恢复控制中心入口。
- **首次下载准备反馈优化**：下载完成后进度条平滑过渡，在宿主解析、依赖准备与包管理器检查阶段注入细致可行动的中文提示，缓解长时等待焦虑。

### 🐛 缺陷修复 (Bug Fixes)
- **启动进度卡顿**：修复 Local 模式下 Node.js 运行时下载到 100% 后进度卡片长时间驻留的问题。
- **控制中心窗口防护**：修复 Windows 平台从胶囊唤起控制中心窗口在 WebView2 异步加载阶段出现白屏闪烁的问题。
- **WSL 工具链探测**：修复检测到 WSL 缺少 Node 时直接中断报错、未触发自动补齐的问题。

## [v0.9.2] - 2026-09-01

### 🌟 核心亮点 (Highlights)
- **插件中心一体化与凭据识别升级**：市场与已安装总览合并为插件中心；模型凭据支持大写环境变量与别名识别；跨 Profile 导入按插件去重折叠，交互与视觉全面对齐设计规范。

### ✨ 新增功能 (Features)
- **插件中心统一视图**：Profile 管理器视图收敛为单入口，市场与已装插件以子 Tab 承载，全量插件发现与已装管理同屏流转。
- **Release Notes 规范化体系**：建立标准模板 `docs/templates/release-notes-template.md` 与生成规范 `docs/prompts/release-notes.md`；构建期脚本优先从 `docs/RELEASE_NOTES.md` 精准提取版本日志。

### 🛠️ 体验与交互优化 (Improvements)
- **跨 Profile 安装弹窗去重折叠**：同名插件按包名聚合，提供来源 Profile 标签切换器，独立绑定配置复制逻辑，消除多来源平铺歧义。
- **文本截断悬浮提示全量补齐**：插件市场、卡片与概览页面的标题、描述与安装源等截断文本处增加 hover 完整查看。
- **模型凭据卡片防折行优化**：去除重复标题显示，增加状态徽标防换行控制，保持布局紧凑整齐。
- **选择器与表单体验优化**：修复 SelectTrigger 内部元素导致的非预期文本截断，统一「安装源」规范命名并移除多余只读标签。
- **Profile 列表下拉操作文案精简**：下拉菜单操作按钮优化为直观的「重命名」和「删除」，消除多余的冗余前缀。
- **插件市场与前端设计规范对齐**：全面清理前端页面非标准 emoji 与硬编码符号，分类与徽章统一采用 `lucide-react` 矢量图标与设计系统颜色。

### 🐛 缺陷修复 (Bug Fixes)
- **模型凭据**：修复配置了 `refs.DEEPSEEK_API_KEY` 时界面仍提示未配置的识别缺失问题。
- **插件安装选择器**：修复跨 Profile 安装时同名插件重复平铺的问题。
- **Profile 详情**：修复重命名操作的提示文案歧义。

### 🔒 架构、安全与稳定性 (Security & Stability)
- **凭据原子写入**：严格维持 `.credentials.yaml` 的 `0600` 权限与原子写入，保障密钥安全。
- **IPC 收敛**：下线 `reset_profile_dependencies` 入口，依赖自愈回归 pnpm 自动补齐链路，网络面与授权面同步收紧。
