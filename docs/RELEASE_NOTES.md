# DSH Dock 版本发布与升级日志 (Release Notes)

> 本文档记录 DSH Dock 各版本的核心演进、功能特性、交互优化与缺陷修复历史。

---

## [v0.9.1] - 2026-09-01

### 🌟 核心亮点 (Highlights)
- **交互细节与凭据管理体验升级**：跨 Profile 安装插件去重折叠；模型凭据卡片防折行与大写环境变量深度支持；插件市场文本悬浮完整查看与规范字段对齐；全面对齐无 Emoji 严谨设计规范。

### ✨ 新增功能 (Features)
- **大模型凭据环境变量与别名识别**：模型凭据解析支持 `refs.DEEPSEEK_API_KEY`、`OPENAI_API_KEY` 等大写与自定义环境变量格式，准确反映已配置状态。
- **Release Notes 自动化规范体系**：建立标准模板 `docs/templates/release-notes-template.md` 与生成规范 `docs/prompts/release-notes.md`，构建期脚本优先从本文档精准提取更新日志。

### 🛠️ 体验与交互优化 (Improvements)
- **从其他 Profile 安装弹窗去重折叠**：将同名插件按包名聚合，提供来源 Profile 标签切换器，独立绑定配置复制逻辑，消除多来源平铺歧义。
- **文本截断悬浮提示全量补齐**：在插件市场、卡片与概览页面的标题、描述与安装源等截断文本处增加 hover 完整查看。
- **模型凭据卡片防折行优化**：去除重复标题显示，增加状态徽标防换行控制，保持布局紧凑整齐。
- **选择器与表单体验优化**：修复 SelectTrigger 内部元素导致的非预期文本截断，统一「安装源」规范命名并移除多余只读标签。
- **Profile 列表下拉操作文案精简**：下拉菜单操作按钮优化为直观的「重命名」和「删除」，消除多余的冗余前缀。
- **插件市场与前端设计规范对齐**：全面清理前端页面非标准 emoji 与硬编码符号，分类与徽章统一采用 `lucide-react` 矢量图标与设计系统颜色。

### 🐛 缺陷修复 (Bug Fixes)
- **模型凭据**：修复配置了 `refs.DEEPSEEK_API_KEY` 时界面仍提示未配置的识别缺失问题。
- **插件安装选择器**：修复跨 Profile 安装时同名插件重复平铺的问题。
- **Profile 详情**：修复重命名操作的提示文案歧义。

### 🔒 架构、安全与稳定性 (Security & Stability)
- **凭据原子写入**：严格维持 `.credentials.yaml` 的 `0600` 权限与原子写入，保障密钥安全。

## [v0.9.0] - 2026-08-31

### 🌟 核心亮点 (Highlights)
- **插件中心与系统控制台重磅上线**：集成社区插件市场、全域插件概览、模型凭据管理、会话自愈与健康诊断。

### ✨ 新增功能 (Features)
- **插件市场与生态接入**：提供精选插件目录、分类过滤、一键安装与版本选择。
- **会话自愈维护**：智能扫描损坏的会话 JSONL 记录，支持单项修复与全量一键自愈。
- **系统控制台**：涵盖大模型凭据、DSH 引擎配置、健康诊断大盘与实时日志查看。
