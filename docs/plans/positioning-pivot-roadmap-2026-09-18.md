## 1. 触发事实（2026-09-18 核查，官方源码版）

- 官方桌面壳已成型：Electron 44 + electron-builder，v0.1.6-alpha.2；Developer ID 签名 +
  公证、Windows NSIS 原生安装页 + EV 签名、自更新（Nightly 通道 + 强更弹窗）、
  内置 Node/pnpm/Python 离线运行时、原生故障恢复（禁用第三方 bundle +
  `cordis.patch.yml` 事务锁内备份）、i18n。近 30 天 166 提交。
- 官方**结构性空白**（多为薄壳裁定，非排期问题）：
  1. 无 profile 列表/切换/克隆/删除——只有独占 `profiles/desktop` 单实例，CLI 被禁操作；
  2. 无插件源切换/镜像（README 明示"遵循用户包管配置"）；
  3. 无诊断/日志查看/导出（仅 ≤1200 字符恢复弹窗）；
  4. 无崩溃自动重启守护；
  5. 明示不支持 Linux；WSL 客体无任何概念；
  6. 与 CLI dsh 并存无编排（端口互斥、profile 隔离各管各的）；
  7. 卸载不清理 `~/.dsh`（proposed 未实现）。
- dsh 本体 web 界面管得到 session/workspace/插件页/模型凭据，**管不到** profile 生命周期、
  运行环境、多实例端口、日志诊断、跨 profile 操作。

## 2. 新定位（一句话 + 三动词）

> **dsh-dock = dsh 开发者的第二控制台。官方让你开始用 dsh，dock 让你把 dsh 用出花来。**
> 面向开发者，提供官方裁定不提供、且只依赖 dsh 文件系统契约与 CLI 就能做到的便利。

| 动词 | 含义 | 官方为何不动 |
|:---|:---|:---|
| **隔离** | 多实例、沙箱、并行、逃逸唯一体验 | 官方必须维护"唯一 blessed 体验"，单实例锁是设计而非缺陷 |
| **免抄** | profile / MCP / 凭据 / 镜像源 / 插件的一站式点击化，dsh 未运行时也能操作 | 薄壳裁定 + web 界面只服务当前运行实例 |
| **看见** | 成本、探测、会话、诊断的跨 profile 运营面 | 官方连日志查看器都没有，属纯增量 |

**与官方壳的关系裁定：邻居，不寄生。** 只做邻居级探测（存在检测、端口避让、共存提示），
**不做** attach 官方 Electron 实例内部（端口约定 / token 兑换 / asar 行为均非契约面，
166 提交/月的快变目标会把复现台账拖垮）。此裁定需 ADR-0028 立卷。

**日落触发线**（写死，避免温水煮青蛙）：

| 触发 | 收缩 |
|:---|:---|
| 官方 web 设置内置 profile 管理器 | 「免抄」中 profile 面退役，转向沙箱/并行独有位 |
| 官方支持 Linux 或镜像源切换 | 对应 Later 项当日退役 |
| 上述两栏全部触发 + 「隔离」「看见」均被侵入 | 整体归档，台账与管理面结论上游移交 |

巡检口径：每次官方发版复核 `.agents/notes/proposed/` 动向（并入现有版本节奏巡检）。

## 3. 投资与退役边界

**冻结退役**（不与官方赛跑，存量只修不扩）：

- 官方体验竞争面：boot 下载链做"卖点"的持续投入、升级提示条 UX、安全模式呈现层、
  打包/签名军备。`updates.rs` 的 dsh 下载**降级定位 = 仅服务自家引擎引导**，不再是
  "帮用户装 dsh"的主路径（用户装官方 dmg 即止）。
- 现 AGENTS §0"把 dsh 以独立可安装桌面应用呈现"的定位表述随之修订。

**保留不动摇**：红线两条（不改 dsh 源码 / 不内置依赖）、IPC/网络面登记制、
三红线、文件系统不变量。

## 4. Now — 第一枪：隔离沙箱 + 并存邻居

> 选此为先的理由：基建全在（`~/.dsh-dock-dev` / `~/.dsh-dock-test` 已验证 DSH_HOME
> 隔离全流程）、官方结构上做不到、故事最"哇"、且是「免抄/看见」两层的底座
> （成本和探测天然按 home 维度聚合）。

| # | 项 | 内容 | 前置 |
|:---|:---|:---|:---|
| N1 | 官方桌面邻居探测 | 只读检测 `profiles/desktop` 存在、19387 端口占用、官方安装痕迹；diagnostics 呈现；**永不写触碰**官方独占 profile；端口冲突自动避让 | ADR-0028（邻居边界） |
| N2 | 沙箱 dsh（隔离环境） | 「为这个项目新建隔离 dsh」：独立 DSH_HOME（放 `<app_data>/sandboxes/<name>`，登记 §6 例外册）+ 独立端口 + 坏了即弃（删除 = 回收目录）；列表/进入/销毁 | ADR-0028；spawn 一律 `lifecycle::spawn` |
| N3 | 免抄存量收口 | 把已落地大项的**未闭合小尾**清掉：workspace CRUD（9-15 巡检确认零 IPC，上游已有 `@Remote`）；MCP 工具列表/连接状态（probe 骨架已有）；凭据引用检查；重置 profile 依赖 | 无，逐项照旧流程 |

**Now 退出判据**：用户能在 dock 里 30 秒内开出一个与官方桌面/主 `~/.dsh` 互不干扰的
沙箱 dsh 并一键销毁；dock 启动时能报告官方桌面共存状态；N3 四尾各带测试合入。

## 7. 明确不做（本轮新增进 §5 不做清单）

| 方向 | 原因 |
|:---|:---|
| attach / 接管官方桌面壳内部（端口、token、asar 行为） | 非契约面 + 166 提交/月快变目标，台账不可承受；只做邻居探测（§2 裁定） |
| 与官方拼装机/签名/自更新/故障恢复体验 | 官方全职主战场，必输；相关链路转维护态 |
| 把 dock 做成"运行 dsh 的推荐方式"对外主推 | 让位官方 dmg；dock 对外话术 = 第二控制台/管理台 |
| 沙箱内自动同步/搬运官方 desktop profile 数据 | 侵犯官方独占 profile 边界（§2 邻居裁定） |
