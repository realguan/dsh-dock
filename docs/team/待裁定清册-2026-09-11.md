## A. 宪法级（`AGENTS.md` / 契约）

### A1 §7 网络面登记缺口 —— 未登记的网络动作【P0，最高优先】

- **事实**：`src-tauri/src/boot.rs:361-405` `authenticate_workbench_session` 用 `ureq` 对
  工作台地址发 HTTP GET（5s 超时、`redirects(0)`），**未见于 AGENTS §7 任何登记处**
  （全仓 grep + 2026-09-04 宪法级广播自述：该次宪法触动项只有 `get_boot_status`）。
  对照：`plugins.rs:199-208` 同形态的环回只读查询**已**登记。
- **冲突**：违反 §7「唯一网络面 = `updates.rs`」与 ADR-0006 §2。
- **方案二选一**：
  - **A①（小）**：§7「已登记用途」补一行「工作台 Token 环回兑换（`boot.rs`，本地 127.0.0.1）」
    —— 承认现状，最小改动。
  - **A②（治本）**：下沉到 `updates.rs` 已有的 `HttpGet` seam —— 与 ADR-0006 精神一致，
    但需排期改码 + 回归。
- **成本警告**：`AGENTS.md` 实测 **恰好 250/250 行**（§11 预算用满），**加一行必须先决定
  回收哪一行**。docs-contract 建议：§7 那份 55 条命令枚举改指针（唯一事实源 =
  `ipc.rs::COMMANDS`，一致性已有 cargo test 闸门），可回收约 20 行。
- **不做后果**：网络面登记册失真——「唯一网络面」是可审计的安全边界，失真后无法据此判断
  新增触网是否越界。

### A2 新增「网络面机器闸门」

- **建议**：仿 `lifecycle.rs:1491` 的 spawn 闸门范式，禁止 `updates.rs` 之外出现网络原语，
  放行需显式标注 `// net-gate: exempt(理由)`。
- **分工建议**：由 `rust-core` 起草（其域内），`docs-contract` 审体例。
- **价值**：把 A1 这类「靠人记得登记」的缺口变成机器可拦。

### A3 §2「main.rs 6 行勿动」措辞精度

- **事实**：`wc -l src/main.rs` = **7** 物理行（含 1 空行），有效代码 6 行。
- **建议**：改「6 行有效代码（7 物理行含 1 空行）」——防未来机器判据按行数做假阳性判定。

### A4 §7 已登记用途漏登「客户端自更新」两路【P1】

- **事实**：`updates.rs:612` `APP_RELEASE_FEED` 与 `updater.rs:28`（含 `tauri.conf` endpoints）
  属网络面，但 §7 只字未提，仅 ADR-0006 §4 有记载。
- **建议**：§7 补登记（可与 A1 一并处理）。

- **事实**：`mcp.rs:192/234` 整数组重序列化写 `cordis.patch.yml` —— **丢注释**且**无备份**；
