## 8. `credentials.rs` 掩码语义的自洽性判断（lead 专项要求）

任务要求我独立判断「按字符数」语义对**短值 / 多字节 / emoji** 是否自洽。我用隔离 rustc 探针（`/tmp`，逐字复制新旧实现）实测：

| 场景 | 输入 | 结果 | 判定 |
| :--- | :--- | :--- | :--- |
| 空串 / 全空白 | `""` / `"   "` | `""` | ✅ 无语义歧义 |
| 短值（≤8 字符） | `"12345678"` / `"密"` / `"密密密密密密密密"`(8 CJK=24B) | `"••••••••"` | ✅ 短值全掩，**判据按字符**（8 CJK 也全掩，旧实现按字节会误入切片分支） |
| 边界 9 字符 | `"123456789"` / `"密密密密密密密密密"` | `"1234••••••••6789"` / `"密密密密••••••••密密密密"` | ✅ ASCII 与多字节同口径 |
| 多字节前后缀 | `"凭据测试值abcd"` | `"凭据测试••••••••abcd"` | ✅ 前缀 4 **字符**（非 4 字节），不 panic |
| **emoji（4 字节码位）** | `"🔑🔑a🔑🔑🔑🔑🔑🔑🔑🔑"`(11 cp) | `"🔑🔑a🔑••••••••🔑🔑🔑🔑"` | ✅ **按 codepoint 计，正确** |
| 组合字符（grapheme 边界） | `"eeee\u{0301}xxxxxxx"`（mark 落在 index 4） | `"eeee••••••••xxxx"` | ⚪ 前缀**丢掉组合重音**——**纯外观**边界，不 panic、不丢字节、无安全隐患 |
| ZWJ 家庭 emoji | `"👨‍👩‍👧xxxx"`(9 cp) | `"👨‍👩‍👧••••••••xxxx"` | ✅ 完整字素落在前缀内，未撕裂 |
| 无 panic 保证 | 全部 13 组输入 | **无一组 panic** | ✅ codepoint 切片在 UTF-8 下**恒为合法边界** |

**结论**：该语义**自洽**，且是本仓库约束下的**正确选择**——要按「字素簇」切需引入 `unicode-segmentation` 依赖，而 AGENTS §5 **禁引依赖**。唯一代价是极端组合字符场景的**外观**边界（前缀丢一个组合重音），**不构成缺陷**。测试注释与实现一致（无「说得对但写得错」）。✅
