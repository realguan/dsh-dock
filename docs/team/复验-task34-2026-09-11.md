## 4. 🔴 依赖纪律闸门**可被静默绕过**（本报告最重要的发现）

### 4.1 闸门与我的独立复算（正面结论：当判据匹配时成立）

`lifecycle_does_not_depend_on_state_holding_sibling_modules` 的判据是逐行匹配三个**含尾随 `::`** 的模式：
`"crate::shell::"` / `"crate::boot::"` / `"crate::ui::"`，并正向要求 `crate::child_cmd(` 存在。

**我用自己的口径独立复算**（切点用 lead 记录的 M4 口径 `"\n#[cfg(test)]\nmod tests"`，600+ 行生产段、剥离注释）：

```text
  生产段行数 = 672
  crate::boot::          实测=0  期望=0  ✅
  crate::ui::            实测=0  期望=0  ✅
  crate::shell::         实测=0  期望=0  ✅
  crate::child_cmd(      实测=1  期望=1  ✅
  生产段全部 crate:: 引用： {'crate::child_cmd': 1}
```

⇒ **与 lead 的粗核 0/0/0/1 完全一致**，且更强：**生产段里 `crate::` 引用总共只有 1 个**。✅ **正面结论成立。**

### 4.2 缺口：`use crate::shell;` + `shell::X()` 不触发任何判据

我做了两次独立注入（均 `trap` 复原，`lifecycle.rs` 每次回到 `8a309917a3896b75`）：

| 注入形态 | 依赖闸门 | 全量 `cargo test` | `clippy -D warnings` |
| :--- | :--- | :--- | :--- |
| `use crate::shell;` + `shell::parse_detected_url(t)`（**非递归**） | **ok（放行）** | **327 passed / 0 failed（全绿）** | **0 error** |
| `use crate::shell;` + `reap_args` 委托 `shell::windows_kill_args`（**互相递归**） | ok（放行） | 101（`reap_args_cover_whole_tree` **stack overflow** / SIGABRT） | — |

**第一条是决定性的**：一条真实的 `lifecycle → shell` 反向依赖**完整地静默形成**——闸门绿、327 测试绿、clippy 绿，**没有任何机器判据发现它**。
**第二条之所以"被抓住"，是偶然的互相递归栈溢出**（`reap_args` ↔ `windows_kill_args`），**不是闸门的功劳**——同一轮里该闸门同样报 `ok`。

**为什么这是现实可达的（不是构造式猎奇）**：
- 闸门的存在理由是**架构约束**（作者注释原文：会形成 `lifecycle ↔ shell` 环、破坏 spawn 闸门单向性证明的地基）；
- 而**用 `use` 引入**恰恰是"想复用它处实现"时最自然的写法——作者的变异 6 用的是 `crate::shell::windows_kill_args`（带 `::`，被拦），但换成 `use crate::shell;` + 短路径调用就绕过了；
- 该形态**编译通过、测试全绿、clippy 干净**，review 也未必注意到 ⇒ **防线在其自身的设计意图上失效**。

### 4.3 修复建议（已核：安全、零假阳性）

当前生产段中 `use crate::shell` / 裸 `shell::` / `use crate::boot` / 裸 `boot::` / `use crate::ui` / 裸 `ui::` **全部为 0 次**（§4.1 实测）⇒ 把 forbidden 列表由三个**含 `::`** 的模式**扩为同时包含**：

```text
"crate::shell::"、"use crate::shell"、"shell::"
"crate::boot::" 、"use crate::boot" 、"boot::"
"crate::ui::"   、"use crate::ui"   、"ui::"
```

**不会误红**（`crate::child_cmd` 白名单不受影响，因其不含 `shell::`/`boot::`/`ui::` 子串）。
> 更稳的写法是「先按 `use` 语句收集本文件引入的 crate 路径，再据此判」——但上表的最小扩充已能关掉本洞。
