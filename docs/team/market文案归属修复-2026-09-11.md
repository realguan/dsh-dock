## 3. 新增键对照表（zh-CN ↔ en-US，均在 `market` 命名空间）

en 侧措辞对齐既有术语：`sourceNpm`/`sourceGithub` 沿用「NPM Package / GitHub Repo」，
`refreshRegistry` 沿用「Refresh」，未逐字直译 zh 语序。

| 键 | 类型 | zh-CN | en-US |
| :--- | :--- | :--- | :--- |
| `reinstallBtn` | string | 重新安装 | Reinstall |
| `installToBtn` | `(prof) => string` | `安装到 ${prof}` | `Install to ${prof}` |
| `installedBadge` | string | 已安装 | Installed |
| `installedInProfile` | `(prof) => string` | `已安装在 ${prof}` | `Installed in ${prof}` |
| `installedWillOverwrite` | string | 已在此 Profile 安装（将执行覆盖/重装） | Already installed in this profile (will overwrite/reinstall) |
| `installedWillReinstall` | string | 已在此 Profile 安装（将覆盖重装） | Already installed in this profile (will be overwritten and reinstalled) |
| `noDescription` | string | 暂无描述 | No description |
| `officialCoreTitle` | string | DSH 官方核心插件 | DSH official core plugin |
| `loadingBtn` | string | 加载中… | Loading… |
| `openLinkFailed` | `(msg) => string` | `打开链接失败: ${msg}` | `Failed to open link: ${msg}` |
| `clearFilters` | string | 清除所有筛选条件 | Clear all filters |

- `installedWillOverwrite`（安装弹窗）与 `installedWillReinstall`（手动安装弹窗）**语义不同、
  不合并**：前者为「确认后入队」路径，后者为「覆盖重装」路径；措辞保留各自原文含义。
- `loadingBtn` **刻意不复用死键 `loadingRegistry`**（后者为「正在连接 Registry 加载目录…」，
  语义不同）；门禁显式断言二者不得相等、按钮态不得出现 registry 字样。
