## 2. 实现

### 2.1 布局与 shim（`engines.rs`）

```
<engines>/
├── bin/{node, pnpm, dsh, dsh.cmd}      # dsh / dsh.cmd = 【新】壳自写 shim（纯文本）
├── dsh-runtime/                        # 【新】dsh 的 project 安装目录
│   ├── package.json                    # 壳写最小声明；依赖条目归 pnpm
│   ├── pnpm-workspace.yaml             # nodeLinker: hoisted（复用 build_policy）
│   └── node_modules/@deepseek-ai/dsh/lib/bin.js
├── node_modules/ store/                # 既有：node 运行时
└── global/                             # 【退役】不再新增；**不主动删**
```

新增函数：

| 函数 | 职责 |
|:---|:---|
| `dsh_runtime_dir(data_dir)` | `<engines>/dsh-runtime/` |
| `dsh_shim_posix(node_bin, entry_js)` | **纯函数** → POSIX shim 文本 |
| `dsh_shim_windows()` | **纯函数** → `.cmd` 文本（ASCII + CRLF + `%~dp0` 相对） |
| `write_if_changed(path, bytes, exec)` | 幂等写（内容+权限位一致 ⇒ 零写入）+ 原子替换 |
| `write_dsh_shim(data_dir)` | 按平台落位 shim |
| `ensure_dsh_runtime_layout(data_dir)` | ① package.json ② hoisted ③ shim（三者幂等） |
| `install_dsh_project_local(...)` | 取代 `install_dsh_global`：镜像链 + project 内 `add` |

shim 形态（与 ADR §4.1 逐字一致）：
- POSIX：`exec "<bin>/node" "<bin>/../dsh-runtime/node_modules/@deepseek-ai/dsh/lib/bin.js" "$@"`
- Windows：`@echo off` + `"%~dp0node.exe" "%~dp0..\dsh-runtime\node_modules\@deepseek-ai\dsh\lib\bin.js" %*`

**两处刻意的形态差异（各有理由，非疏漏）**：
- POSIX 用**绝对路径**（ADR 原文如此；`exec` 一行、不经 PATH 解析 node）；
- Windows 用 **`%~dp0` 相对定位**（`.cmd` 自带脚本目录；引擎目录整体搬迁后仍可用）。
  ⇒ 已在 `both_platform_shims_target_the_same_relative_entry` 钉住「两者指向同一入口」。

### 2.2 复用而非另写（lead 硬要求 #4）

| 复用对象 | 方式 |
|:---|:---|
| `build_policy::ensure_engine_linker(dir)` | **直接调用**（它本就吃任意目录，写 `<dir>/pnpm-workspace.yaml`）⇒ **零新键处理代码**；单键 upsert 唯一实现未动 |

| `run_engine_pnpm_streaming` | 仅**新增 `cwd` 参数**（project 内安装的落点）；`runtime set node` 传 `pnpm_home(data_dir)` = **原行为** |
| `parse_package_progress` / `ProgressStage::Dsh` | 未动，进度口径不变 |

| `install_failure_message`（task-42 的网络/特权分类） | 未动，继续用作失败聚合 |

**未新造**：无 emit、无第二套安装器、无第二份键处理、无第二份 shim 生成。

### 3.1 旧布局兼容 —— 本改动**最可能伤存量用户**处（lead 硬要求 #1）

判据形态：就绪判定**只吃「三件在位 + 版本匹配」**（`readiness_gaps` 只看 `EngineStatus`，
**结构上不可能**依赖布局）。故断言取最强形式：在**同一引擎目录**上先测「无 legacy `global/`」，
再建出存量用户的 `global/v11/<64hex> -> <real>` 符号链接树后复测，要求两次 `probe_engine`
结果**逐字段一致**且均判就绪、`probe_engine_if_ready` 仍走就绪快路径。

⇒ **老用户不会被强制重装**；旧 `global/` **不主动删**（ADR §5.1），本实现无任何删除逻辑。

### 3.2 只改 dsh，不动 node（lead 硬要求 #2）

`runtime_set_node` 的调用点 diff **仅一行**：新增 `&pnpm_home(data_dir)` 作为显式 `cwd`
——即**原行为**（runner 原本就 `current_dir(pnpm_home)`）。`link_real_node_binary`、
`find_runtime_node_bin`、node 镜像链**均未改**。

### 3.3 WSL 客体不动（lead 硬要求 #3）

`executor.rs` 客体脚本 `pnpm add --global`（`:695`）**零改动**（`git diff` 该文件 0 行）。
分叉面**未因本次扩大**；ADR §5.2 的观察项保持原状。

### 3.4 端到端：shim **真的被执行**（离线、hermetic）

`generated_shim_executes_and_forwards_args` 用**生产函数** `write_dsh_shim` 生成 shim，
把 `bin/node` 换成回显参数的假 node，断言：
- node 收到的**第一个**参数 = `dsh-runtime/node_modules/@deepseek-ai/dsh/lib/bin.js`；
- `--version` 与 **含空格的参数** `arg with space` 原样透传（不被拆）。

⇒ 「shim → node → 入口 JS → 参数」这条真实链路已被机器验证，**不依赖真实 Node 二进制**。

> 另在 `/tmp` 做过一次带**真实 node** 的手工 spike（假 dsh 入口 `console.log`）：
> `./eng/bin/dsh --version` 与 `./eng/bin/dsh plugin list "arg with space"` 均正确输出。

## 6. 未决 / 风险

1. **Windows 真机未验**（用户已裁定搁置）：`SeCreateSymbolicLinkPrivilege` 相关的
   实际行为、`.cmd` shim 在 cmd.exe 下的执行、`engines\global\` 是否**不再新增**，
   **只能在真机复验**。ADR §6 已给出真机判据（`bin\dsh.cmd` 存在 + `dsh --version`
   有输出 + 健康大盘三卡就绪 + `global\` 不再新增）。本机证据止于 §2–§4。
2. **shim 位置随引擎目录移动**：Windows shim 用 `%~dp0`（可搬），POSIX shim 用**绝对
   路径**（ADR §4.1 原文如此）⇒ 引擎目录整体搬迁后 POSIX shim 会失效。当前无搬迁路径
   （引擎目录是 app_data 下的壳资产），故**按 ADR 实施**；若将来引入可搬迁引擎目录，
   需一并把 POSIX shim 改为 `$(dirname "$0")` 形式——**登记为观察项，本轮不改**。
3. **`global/` 回收**：ADR §5.1 明确「不主动删」，登记为可回收项。本实现无删除逻辑；
   若将来要做，须先确认无用户进程占用（旧 shim 可能仍指向它）。
4. **升级/回滚语义**：仍走「镜像链逐个尝试 → 全失败才 Err」，`UpgradePlan::Skip/Install`
   未动。**但真实下载/升级未在本机跑过**（需新 Release + 联网），属真机/发版后复验项。
5. **`dsh-runtime` 与 `<engines>/pnpm-workspace.yaml` 的 workspace 关系**：探针实测
   该布局可行（两层各自有 `pnpm-workspace.yaml`），但**未在 Windows 真机复验**；
   若真机出现 workspace 归属异常，排查方向是给 `<engines>/pnpm-workspace.yaml` 显式
   `packages:` 排除 dsh-runtime（**登记为风险，不在本轮加防御**）。
